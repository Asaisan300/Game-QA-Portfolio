# AST-FUN-001 — Character Movement and Exploration

**Type:** Functional  
**Priority:** High  
**Status:** Tested

## Objective

Verify that the player character can move through the accessible game world and interact with the environment as intended.

## Preconditions

* The game is running.
* The player has control of the character.
* The character is in an accessible gameplay area.

## Test Steps

1. Move the character forward, backward, left, and right.
2. Change movement direction while the character is moving.
3. Rotate the camera while moving.
4. Navigate across different terrain and elevation changes.
5. Approach environmental obstacles and objects.
6. Enter and exit accessible areas.
7. Observe the character's position relative to the environment during movement.
8. Continue exploring the accessible area for several minutes.

## Expected Result

* Character movement responds correctly to player input.
* The character moves consistently in all available directions.
* Camera movement does not interfere with character control.
* The character navigates terrain and elevation changes correctly.
* Environmental collision behaves as expected.
* The character remains correctly positioned relative to the environment.
* The player does not become unexpectedly stuck or unable to move through accessible areas.

## Actual Result

All tested movement and exploration behaviors functioned as expected.

## Test Result

**Pass**
