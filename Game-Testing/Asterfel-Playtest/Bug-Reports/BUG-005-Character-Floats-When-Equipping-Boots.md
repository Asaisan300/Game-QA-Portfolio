# BUG-005 - Character Floats When Equipping Boots

## Description

Equipping any available pair of boots causes the player character to float slightly above the ground.

The issue occurs regardless of the terrain where the boots are equipped.

## Steps to Reproduce

1. Launch build V.0.0.4.2.
2. Locate any available pair of boots.
3. Equip the boots.
4. Observe the character's position relative to the ground.
5. Repeat the test with another pair of boots and on different terrain.

## Expected Result

The character should remain correctly positioned on the ground after equipping boots, regardless of the terrain or specific pair of boots equipped.

## Actual Result

The character floats slightly above the ground after equipping any available pair of boots. The issue occurs regardless of the terrain.

## Repro Rate

100%

## Severity

Medium
