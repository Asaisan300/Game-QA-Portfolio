# AST-FUN-005 — Crafting and Resource Systems

**Type:** Functional  
**Priority:** High  
**Status:** Tested

## Objective

Verify that available resource-gathering and crafting mechanics function correctly during gameplay.

## Preconditions

- The game is running.
- The player has access to at least one resource-gathering mechanic.
- The player has access to a relevant crafting station or crafting system.
- Required resources can be obtained.

## Test Steps

1. Gather an available resource.
2. Observe the resource and inventory state.
3. Access an available crafting station or crafting interface.
4. Select an available craftable item.
5. Review the required materials.
6. Craft the selected item.
7. Observe the inventory after crafting.
8. Repeat the process with another available crafting or resource-gathering system if applicable.

## Expected Result

- Available resources can be gathered successfully.
- Gathered resources are correctly added to the player's inventory.
- Crafting interfaces function correctly.
- Required materials are correctly recognized.
- Crafting consumes the appropriate resources.
- Crafted items are successfully added to the player's inventory or available equipment.
- Crafting and resource-gathering systems function without unexpected behavior.

## Actual Result

All tested crafting and resource-gathering behaviors functioned as expected.

## Test Result

**Pass**
