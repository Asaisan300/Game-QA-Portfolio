# BUG-005: Language Setting Does Not Change Language

## Description

The language setting does not change the selected language when the navigation arrows are pressed. The button responds with visual and audio feedback, but the language remains unchanged.

## Steps to Reproduce

1. Launch build 24305160.
2. Open the Settings menu.
3. Locate the Language setting.
4. Click the arrows next to "English" to select another language.

## Expected Result

The selected language should change when the navigation arrows are pressed.

## Actual Result

The language remains set to English, even though visual and audio feedback is triggered when the arrows are pressed.

## Repro Rate

5/5 attempts

## Severity

Low
